# 템플릿 06 — 메타 프롬프트 (Layer 채우기 막힐 때)

> 5-Layer 채우는 게 어려우면 LLM에게 프롬프트 자체를 작성해 달라고 시킨다.

```
@VIBE_CODING.md 기준.

나 [기능명] 을 만들어야 해. 어떻게 5-Layer로 적어야 할지 모르겠어.

알고 있는 것:
- (대략의 의도)
- (사용자가 무엇을 보고/하게 되는지)
- (관련된 산출물 — 알면 적기)

모르는 것:
- (예: API 응답 모양, 테이블, 컴포넌트 분해 등)

요청:
Layer 3(Task)와 Layer 5(Output) 초안을 만들어줘.
- 모르는 항목은 [TODO] 표시로 비워서 내가 채울 수 있게
- 비슷한 기존 패턴(어떤 도메인/페이지 참고)도 1-2줄로 알려줘
- 첨부해야 할 산출물 (ERD.md / Wireframes.md / API_명세서.md / Sequence_Diagrams.md / COMPONENTS.md / STYLE_GUIDE.md) 중 어느 것이 필요한지 명시
```

## 결과를 받은 다음
- LLM이 채워준 초안의 [TODO] 부분만 본인이 채움
- 그대로 [템플릿 01-04 중 하나]로 정리해서 본 작업 프롬프트로 사용
