# 통합 테스트 체크리스트

## 1. 인증 흐름

- [ ] 회원가입 성공
- [ ] 로그인 성공
- [ ] accessToken 발급 확인
- [ ] 로그인 후 인증 필요한 API 호출 가능

## 2. 단어 조회 흐름

- [ ] words 테이블에 단어 데이터 존재
- [ ] GET /api/words 호출 성공
- [ ] 응답 필드 id, english, korean, level, type, example 확인

## 3. 퀴즈 진행 흐름

- [ ] GET /api/quizzes?type=MEANING_TO_WORD 호출 성공
- [ ] 문제 목록 반환 확인
- [ ] 각 문제에 wordId 포함 확인
- [ ] choices 배열 포함 확인
- [ ] correctAnswer 처리 방식 확인

## 4. 결과 저장 흐름

- [ ] 퀴즈 완료 후 POST /api/quiz-results 호출
- [ ] quiz_results 테이블에 전체 결과 저장 확인
- [ ] quiz_result_details 테이블에 문제별 결과 저장 확인
- [ ] 저장 후 quizResultId 반환 확인

## 5. 결과 조회 흐름

- [ ] GET /api/quiz-results/{quizResultId} 호출 성공
- [ ] 정답 수, 점수, 제출 시간 확인
- [ ] 문제별 정답/오답 리스트 확인
- [ ] 프론트 결과 화면과 연결 확인
