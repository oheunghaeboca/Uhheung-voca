# 통합 테스트 체크리스트

## 1. 인증 흐름

- [ ] 회원가입 성공
- [ ] 로그인 성공
- [ ] accessToken 발급 확인
- [ ] 로그인 후 인증 필요한 API 호출 가능

## 2. 단어 조회 흐름

- [ ] words 테이블에 단어 데이터 존재
- [ ] GET /api/words 호출 성공
- [ ] 응답 필드 id, english, korean, level, type, example 확인

## 3. 퀴즈 진행 흐름

- [ ] GET /api/quizzes?type=MEANING_TO_WORD 호출 성공
- [ ] 문제 목록 반환 확인
- [ ] 각 문제에 wordId 포함 확인
- [ ] choices 배열 포함 확인
- [ ] correctAnswer 처리 방식 확인

## 4. 결과 저장 흐름

- [ ] 퀴즈 완료 후 POST /api/quiz-results 호출
- [ ] quiz_results 테이블에 전체 결과 저장 확인
- [ ] quiz_result_details 테이블에 문제별 결과 저장 확인
- [ ] 저장 후 quizResultId 반환 확인

## 5. 결과 조회 흐름

- [ ] GET /api/quiz-results/{quizResultId} 호출 성공
- [ ] 정답 수, 점수, 제출 시간 확인
- [ ] 문제별 정답/오답 리스트 확인
- [ ] 프론트 결과 화면과 연결 확인

## 6. 오늘의 단어 추천 흐름 (PBI-11)

- [ ] 토큰 없이 GET /api/words/daily → 401
- [ ] 토큰 포함 GET /api/words/daily → 200 + words 배열 20개
- [ ] 응답 필드 wordId, english, korean, level, type 확인
- [ ] 같은 날 같은 사용자에게 두 번 호출 시 words[].wordId 시퀀스 동일 (멱등성)
- [ ] WordDetailPage 또는 FlashcardPage 에서 단어를 본 뒤 다시 GET /api/words/daily 호출 → 해당 단어가 응답 후순위로 밀리거나 빠짐 (학습 이력 적은 단어 우선)
- [ ] 대시보드에서 TodayWordsCard 의 가로 스크롤 단어 카드 표시 확인

## 7. 단어 학습 이벤트 기록 흐름 (PBI-12 B-옵션)

- [ ] 토큰 없이 POST /api/words/{wordId}/view → 401
- [ ] 토큰 포함 POST /api/words/{wordId}/view → 204
- [ ] 존재하지 않는 wordId 호출 → 404 WORD_NOT_FOUND
- [ ] word_study_events 테이블에 user_id, word_id, studied_at 행 INSERT 확인
- [ ] WordDetailPage 진입 시 자동으로 POST /api/words/{id}/view 호출 (Network 탭 확인)
- [ ] FlashcardPage 카드 넘김마다 같은 호출 발생 확인

## 8. 데일리 미션 흐름 (PBI-12)

- [ ] 토큰 없이 GET /api/missions/today → 401
- [ ] 신규 사용자가 토큰 포함 호출 → 200, missions 3건 모두 current=0, allCompleted=false, attendanceGranted=false
- [ ] 응답 missions[*] 필드 missionType, description, target, current, isCompleted 확인
- [ ] missionType 값이 STUDY_WORDS / TAKE_QUIZ / SCORE_70 인지 확인
- [ ] 단어 20개를 단어 학습 페이지에서 본 뒤 재호출 → STUDY_WORDS.current=20, isCompleted=true
- [ ] 퀴즈 1회 응시·제출 후 재호출 → TAKE_QUIZ.current=1, isCompleted=true
- [ ] 퀴즈 점수 70 이상이면 SCORE_70.isCompleted=true, 미만이면 false
- [ ] 세 미션 모두 충족된 상태로 호출 → allCompleted=true, attendanceGranted=true
- [ ] attendance 테이블에 user_id, date 행이 1개 INSERT 됨
- [ ] 같은 날 재호출 → 두 번째 INSERT 발생하지 않음 (멱등)
- [ ] daily_missions 테이블에 user_id, date 행이 1개만 존재 (UNIQUE 제약 확인)
- [ ] 대시보드에서 TodayMissionCard 의 progress bar 3개 + "🏅 오늘 출석 인정!" 배지 표시 확인

## 9. PBI-11/12 통합 동작 (학습 이력 정의 일관성)

- [ ] 사용자 A 가 단어 X 를 학습 페이지에서 5번 봄 → POST /words/X/view 5건
- [ ] GET /api/words/daily 호출 → 단어 X 가 응답 후순위 또는 미포함 (PBI-11 의 cnt 가 5)
- [ ] GET /api/missions/today 호출 → STUDY_WORDS.current 가 1만 증가 (distinct word 카운트)
- [ ] 위 두 응답에서 "학습됨" 의 어휘가 같은 테이블(word_study_events)에서 유도됨을 확인 (퀴즈 응시 단어가 PBI-11 추천에 영향 주지 않음)
